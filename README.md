# Pomodoro Timer

Um pomodoro timer simples feito principalmente para praticar JS e entender melhor como trabalhar com:

* Manipulação do DOM
* `setInterval` e controle de tempo
* Eventos e botões
* Alteração de elementos na página
* Organização básica de um projeto com JavaScript

## Como funciona

O timer começa com **25 minutos** de foco. Quando o tempo acaba, é possível iniciar o período de descanso.

Também dá para pausar, continuar e resetar o timer.

## Tecnologias

* HTML
* CSS
* JavaScript
